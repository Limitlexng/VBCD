# PixelVault Ecommerce (Digital Products)

A lightweight ecommerce storefront for selling downloadable digital products.

## Features

- Product catalog with search and category filtering
- Cart with quantity tracking and subtotal
- Demo checkout form and instant fulfillment flow
- Persistent cart and order history via localStorage
- Customer library with download buttons for purchased files

## Run locally

Because this app is static HTML/CSS/JavaScript, you can run it with any local web server:

```bash
python3 -m http.server 8000
```

Then open: <http://localhost:8000>

## Notes

- Checkout is a demo-only flow (no real payments).
- Downloaded files are generated placeholders to simulate digital delivery.
